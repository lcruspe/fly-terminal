# Fly Terminal updater

`Tools → Обновить Fly Terminal` обслуживается `tools/update_stack.py`.

## Порядок обновления

1. `git fetch origin main`;
2. проверка локальных изменений отслеживаемых файлов;
3. автоматическая очистка только заведомо генерируемых macOS-артефактов (`.DS_Store`);
4. `git pull --ff-only origin main`;
5. перезапуск LaunchAgents Fly Terminal;
6. проверка готовности сервисных портов.

Пользовательские изменения исходников никогда не сбрасываются автоматически. Если после очистки безопасных артефактов остаются изменённые tracked-файлы, обновление останавливается и status JSON перечисляет конкретные пути.

## `.DS_Store`

`.DS_Store` запрещён в репозитории через `.gitignore` и удалён из `main`. Это важно для macOS-инсталляции: Finder может менять такой файл независимо от Fly Terminal, и ранее это ошибочно блокировало preflight обновления как локальное изменение проекта.

Для старых checkout, где `.DS_Store` ещё отслеживается старой версией Git и старый updater уже заблокирован, требуется однократное восстановление файла из текущего локального HEAD перед первым pull. После получения актуального `main` повторяться это не должно.
