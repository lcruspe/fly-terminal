# Colima / Lima: Krunkit с Free Page Reporting

Локальная сборка для Mac mini Apple Silicon. Исходные версии: Colima v0.10.2 (1afe7c4771501eaae2dc1cbe506c4a67609ed151), Lima v2.1.2 (2d4314e945cda21ed777fe73a078619f23fc48df). Krunkit 1.3.2 и libkrun 1.19.8. Глобальный Homebrew Lima не изменяется: отдельная VM Tailscale продолжает использовать его.

## Состав исправлений

- Colima: точная проверка mountpoint вместо поиска файловой системы, содержащей путь; для Krunkit VirtioFS вместо 9p; проверка метки диска до bind mount; systemd ExecStartPre проверяет точную точку монтирования, метку и подкаталог Docker/containerd; штатная остановка размонтирует постоянный диск после остановки runtime и sync.
- Lima: в Krunkit cloud-init ISO занимает vdb, поэтому первый дополнительный диск — vdc. Учитывается в генерации cidata; покрыто точечным тестом. Для VZ/QEMU порядок не меняется.
- SSH over vsock отключён локальным override Colima (в Lima 2.1.3 уже исправлено поведение по умолчанию).

## Сборка и запуск

`build.sh /абсолютный/путь/на/внешнем/SSD/новый-каталог` — воспроизводимая отдельная сборка из закреплённых тегов и патчей. Не изменяет Homebrew. Требуются установленные Lima 2.1.2, Krunkit/libkrun, Xcode CLT, доступ к исходникам и Go. SHA256 архива Go проверяется, запускаются тесты кода. Собранные бинарники подписываются ad hoc; неизменённые гостевой агент и драйвер хранятся в отдельном префиксе.

`colima-wrapper.sh` рядом с собранными файлами запускает исправленную Colima с собственным limactl в PATH только для её дочерних процессов. Для управления Krunkit использовать именно этот wrapper. Не использовать Homebrew `brew services start/restart colima` и обычные `colima start/stop/restart` для рабочего Krunkit: они обойдут исправления. Обычная Lima остаётся необходимой для Tailscale.

`cutover.sh` — **специальный сценарий однократной миграции данного Mac mini**. Требует успешного полного теста на изолированной копии (лог, состояние Stopped), сохраняет оригинальные VZ root/data/config отдельно, использует новый APFS-клон реального диска, проверяет инвентарь, сервисы, облачную инициализацию, endpoint-ы и отдельные VPN. Не запускать на другой машине или повторно без адаптации; не удалять каталоги отката. Автозапуск — отдельный LaunchAgent com.fly-terminal.colima со scoped wrapper. Исполняемые файлы и companion driver/guest-agent копируются в ~/Library/Application Support/FlyTerminal/colima-krunkit (небольшой внутренний префикс, т.к. launchd не может исполнять файл с внешнего SSD без разрешения). Сборка и все диски остаются на внешнем SSD. Перед cutover запустить permission-check.sh и подтвердить штатный запрос macOS о доступе colima-fixed-v2 к съёмному диску. Проверка выполняет только status без остановки VZ; cutover проверяет успешный выход preflight и совпадение SHA256 установленных бинарников. Не отключать TCC и не изменять базы разрешений. При неуспехе процедура возвращает прежний VZ и сохраняет кандидата для диагностики.
