# YT Transcript для Mac mini

Отдельный локальный сервис в `~/youtube-transcriber-local`, запускаемый LaunchAgent `com.kruspe.yttranscriber` на 127.0.0.1:8787 и доступный через `/yt-transcriber/`. Существующая cookie-сессия и API для инструментов сохранены. Секреты задаются в окружении LaunchAgent и в репозитории не хранятся.

Веб-интерфейс создаёт задания через `POST /api/ui/jobs`. Однопоточная очередь сохраняет их в `jobs.sqlite3` рядом с приложением, а интерфейс опрашивает `GET /api/ui/jobs` и `GET /api/ui/jobs/{id}`. SQLite содержит URL, названия видео, статусы, ошибки и готовые тексты; файл и его резервные копии необходимо считать личными данными. История показывает до 200 последних задач. Закрытие браузера не останавливает обработку на Mac; после перезапуска сервиса незавершённые задания запускаются заново. Во время задания `caffeinate` предотвращает автоматический сон Mac; принудительный сон или выключение всё равно останавливают обработку до пробуждения и запуска сервиса.

Показываются фактические этапы: метаданные, субтитры, загрузка модели и аудио, распознавание; проценты отображаются только при наличии измеримых данных и относятся к текущему этапу. Ошибка остаётся в истории. Субтитры YouTube могут вернуть 429, после чего используется Whisper; загрузка видео также может завершиться ошибкой. Ранее выполненные синхронные запросы не могут быть автоматически восстановлены, если результат не был сохранён.

Для обновления скопировать `app.py`, `jobs.py`, `web.html` в каталог сервиса и перезапустить LaunchAgent после завершения имеющихся синхронных запросов. Сохранить `jobs.sqlite3`, `tool_cache`, `transcripts`, `.venv`, иконку и конфигурацию авторизации. Для проверки использовать изолированный временный каталог и замены сетевых функций, не удаляя рабочую базу.
